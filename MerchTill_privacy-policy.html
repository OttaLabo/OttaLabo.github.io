プライバシーポリシー

物販レジ

本アプリはお客様のデータを一切外部に送信しません。すべての情報はお使いの iPhone 端末内にのみ保存され、開発者を含む第三者がアクセスできない状態で扱われます。

1. 適用範囲

本ポリシーは、iOS 向けアプリ「物販レジ」（以下「本アプリ」）におけるユーザー情報の取扱いについて定めるものです。本アプリは、個人主催のライブ・イベント現場での物販レジ業務を支援する目的で提供されています。

2. 本アプリが取り扱う情報

本アプリは、ユーザーが本アプリ内で入力・登録した以下の情報のみを取り扱います。これらはすべてお使いの端末内にのみ保存されます。

項目内容保存場所
商品マスタ 商品名、税込価格、メモ、並び順、表示ON/OFF、商品画像 端末内（SwiftData ローカルストア / アプリのサンドボックス内ファイル）
取引履歴 会計日時、合計金額、預かり金額、おつり、決済手段、商品明細のスナップショット、取消フラグ、メモ 端末内（SwiftData ローカルストア）
キャッシュレス決済手段 表示名（例: PayPay）、並び順、表示ON/OFF 端末内（SwiftData ローカルストア）
アプリ設定 ハプティクス ON/OFF、商品カードのタップ動作 など 端末内（UserDefaults）

氏名、メールアドレス、電話番号、位置情報、広告識別子（IDFA）、端末識別子（IDFV 等）といった個人情報や識別情報は一切取得しません。

3. ネットワーク通信

本アプリは外部サーバーとの通信を一切行いません。機内モードや圏外でも全機能が動作します。

  • 分析ツール（Google Analytics、Firebase Analytics、その他 SDK）は組み込まれていません。
  • クラッシュレポートの送信機能はありません。
  • 広告の配信および計測は行いません。
  • 外部の決済サービス（PayPay、楽天Pay 等）との API 連携はありません。キャッシュレス会計は別端末・別アプリで決済済みであることを前提に、本アプリでは「記録」のみを行います。

4. カメラ・写真へのアクセス

商品画像の登録において、以下のアクセスを必要に応じて使用します。いずれの場合も、取得した画像は本アプリのサンドボックス内（Documents/products/）に JPEG として保存され、アプリ外には送信されません。

  • カメラ: ユーザーが「カメラで撮影」を選択したときのみ起動します。初回利用時に iOS のシステムダイアログで許可を求め、許可されない場合はカメラ機能を使用しません。
  • フォトライブラリ: ユーザーが「ライブラリから選択」を選択したとき、iOS 標準の Photos Picker を表示します。Photos Picker は OS が管理する独立した仕組みで、ユーザーが選んだ画像のみが本アプリに渡されます。本アプリはフォトライブラリ全体へのアクセス権限を要求せず、ユーザーが明示的に選択した画像以外を読み取ることはできません。

5. データのエクスポート

本アプリには、ユーザーが任意で行えるデータ書き出し機能があります。書き出されたファイルの送信先・保存先は、iOS 標準の共有シート（Share Sheet）でユーザー自身が選択します。本アプリは外部送信処理に関与しません。

  • 売上履歴の CSV エクスポート
  • 商品マスタの JSON エクスポート / インポート

6. 第三者への提供

本アプリは、ユーザー情報を第三者に提供することはありません。前述のとおり、データは端末内にのみ存在し、開発者を含めてアクセスできない状態で保持されます。

7. データの保管期間と削除

本アプリ内のデータは、ユーザーがアプリ内の操作（商品の削除・取引の取消など）を行うか、本アプリをアンインストールするまで端末内に保持されます。アンインストールすると、本アプリが管理する全データ（商品マスタ、取引履歴、画像ファイル、設定値）が端末から完全に削除されます。

8. お子様のプライバシー

本アプリは年齢に関する情報を取得せず、特定の年齢層を対象としていません。お子様が本アプリをご利用になる場合は、保護者の方の管理のもとでご利用ください。

9. セキュリティ

本アプリのデータは、iOS が提供する標準のアプリケーションサンドボックスとファイル保護機構の下で保存されます。情報を保護するため、端末本体のパスコード設定および Face ID / Touch ID を有効にしておくことを推奨します。

10. プライバシーポリシーの変更

本ポリシーは、法令の改正や本アプリの機能変更等にともない、予告なく改定されることがあります。重要な変更がある場合は、本アプリのアップデートリリースノートまたは本ページ上で告知します。
